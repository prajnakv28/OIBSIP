# OIBSIP - Data Science Internship

Hi, I'm Prajna! This repo has all my task submissions for the Oasis Infobyte Data Science internship (July 2026).

I'm doing this internship alongside prepping for data analytics roles, so I tried to actually understand what I was building rather than just getting it done - each folder has a notebook, the dataset I used, a README explaining what I did, and some screenshots of the key charts.

## Tasks I've completed so far

**Task 1 - Iris Flower Classification**
Classic beginner ML project - used the Iris dataset to train a couple of classifiers (Logistic Regression and KNN) to predict flower species from petal/sepal measurements. Both ended up hitting 100% accuracy on the test set, mostly because petal measurements separate the species really cleanly.
👉 [DataScience-Task1-IrisClassification](./DataScience-Task1-IrisClassification)

**Task 2 - Unemployment Analysis with Python**
This one's pure EDA, no ML. Looked at state-wise unemployment data in India through 2020 and tried to quantify how badly the COVID lockdown hit employment. Turns out average unemployment jumped about 40% after lockdown started, and it took months to recover. Haryana and Tripura had it worse than everyone else.
👉 [DataScience-Task2-UnemploymentAnalysis](./DataScience-Task2-UnemploymentAnalysis)

**Task 5 - Sales Prediction Using Python**
Built regression models to predict sales from advertising spend (TV/Radio/Newspaper). Random Forest did way better than plain Linear Regression here (R² of 0.98 vs 0.90). Interesting finding - Radio ads actually give the best bang for your buck, while Newspaper spend barely moves the needle on sales.
👉 [DataScience-Task5-SalesPrediction](./DataScience-Task5-SalesPrediction)
